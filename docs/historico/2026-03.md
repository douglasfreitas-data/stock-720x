## Sessão 13/03/2026 (Noite)

**Horas**: 1.0h  
**Foco**: Recuperação de Incidente Vercel + Decisão de Pivot (Push → Popup)

### Atividades
- **Incidente de Deploy (Vercel)**:
  - Identificados 10+ deploys consecutivos com erro após commits de Web Push Notifications.
  - Causa-raiz: biblioteca `web-push` (Node nativo) + alterações conflitantes no `vercel.json`.
  - **Rollback forçado** para commit `8a360bb` (último estado estável), descartando 6 commits.
  - Relatório completo: `docs/rastreamento/INCIDENTE_VERCEL_2026-03-13.md`.
- **Decisão: Abandonar Web Push → Popup In-App**:
  - Notificações Push descontinuadas por incompatibilidade com Vercel/Edge.
  - Nova abordagem: Popup persistente ao login com alertas de estoque mínimo.
- **Proteção de Produção (Workflow)**:
  - Atualizado `/iniciar` com pré-voo obrigatório de saúde do deploy.
- Adicionado passo de criação de branch `dev` e CI/CD no workflow.
  - Atualizado `01_ROADMAP_MACRO.md` e `02_FASE_ATUAL.md` com novas prioridades.
