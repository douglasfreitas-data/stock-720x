## 3. Decisão de Produto: Pivot Push → Popup

### ❌ Web Push Notifications (Descontinuado)
- Incompatível com Vercel (biblioteca `web-push` usa Node nativo)
- Requer Service Worker, chaves VAPID, tabela de subscriptions
- Complexidade desproporcional para o benefício

### ✅ Popup de Estoque Mínimo (Nova Abordagem)
Ao logar no sistema, exibir um **popup/modal persistente e destacado** listando todos os produtos com estoque ≤ mínimo ideal.

**Comportamento esperado:**
1. Ao fazer login, consultar `product_variants WHERE stock <= min_stock`
2. Se houver resultados, exibir modal com a lista
3. Para cada produto, dois botões:
   - **"Lembrar Depois"** → Fecha o modal, volta a aparecer no próximo login
   - **"Não avisar mais sobre este produto"** → Grava no Supabase (`alert_preferences`) para silenciar

**Vantagens:**
- 100% client-side + Supabase (sem bibliotecas nativas)
- Sem Service Worker, sem VAPID, sem endpoint de push
- Funciona em qualquer navegador/plataforma
- Simples de implementar e manter
